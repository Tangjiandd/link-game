# 小小连连看

这是一个包含两个发布目标的完整项目：

- `web/`：可免费部署为 PWA 的网页版本。iPad 可从 Safari 添加到主屏幕，获得接近独立 App 的体验。
- `miniprogram/`：原生微信小程序版本。导入微信开发者工具后可直接真机预览、上传并提交发布。

## 重要说明

`127.0.0.1` 只指向启动服务器的那台电脑，其他 iPad 和手机无法访问。因此本项目不把本地地址当作发布方案。

App Store 不能免费公开上架：需要加入 Apple Developer Program，并支付 Apple 当前要求的年费，再通过审核。对于免费使用且希望在 iPad 上像 App 一样打开，推荐发布 `web/` 到 GitHub Pages、Cloudflare Pages 或 Netlify，再从 iPad Safari“添加到主屏幕”。

微信小程序的发布不依赖你的电脑持续开机。审核发布后，用户通过微信搜索、二维码或分享链接打开。

## 方式一：免费部署到 iPad

推荐 Cloudflare Pages 或 GitHub Pages。两者都是静态托管，不需要服务器和数据库。

### Cloudflare Pages

1. 将 `web/` 中的全部文件上传到一个 Git 仓库。
2. 在 Cloudflare Pages 新建项目并连接该仓库。
3. 构建设置选择“无框架”，构建命令留空，输出目录填写 `web`。
4. 部署完成后会得到一个 HTTPS 网址。
5. 在 iPad Safari 打开网址，点击“分享”按钮，选择“添加到主屏幕”。

首次通过 HTTPS 打开后，离线缓存会自动生效。以后即使没有网络，已打开过的游戏也可以继续游玩。

### 本地开发

在本项目根目录运行：

```bash
python3 -m http.server 8080 --directory web
```

本机浏览器访问 `http://127.0.0.1:8080`。这只用于开发，不是外部发布链接。

## 方式二：发布微信小程序

1. 注册并完成微信小程序账号认证，然后取得自己的 AppID。
2. 安装并打开微信开发者工具，选择“导入项目”。
3. 选择本目录的 `project.config.json`，将默认的 `touristappid` 换成你的 AppID。
4. 开发者工具会自动识别 `miniprogram/` 为小程序代码目录。点击“编译”，再使用“真机调试”让 iPad/手机上的微信预览。
5. 检查完成后点击“上传”，在微信公众平台提交审核并发布。

小程序不需要后端、域名或服务器，所有闯关进度仅保存在孩子使用的本机上。

## 项目结构

```text
连连看/
  project.config.json              微信开发者工具配置
  miniprogram/                     原生微信小程序
    pages/home/                    游戏页面与逻辑
  web/                             PWA 网页版本
    manifest.webmanifest           主屏安装信息
    sw.js                          离线缓存
```

## 玩法设计

- 三个主题关卡：动物、果园、海底。
- 规则为标准连连看：两个相同图块可用不超过两次拐弯的路径相连。
- 适合低龄孩子：没有倒计时、没有失败惩罚，支持提示、重玩和自动防卡关整理。
